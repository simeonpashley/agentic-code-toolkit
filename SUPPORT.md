# Support

No support is offered for this toolkit. There is no help desk, no
service-level agreement, and no commitment to respond to questions.

The full position is in the
[Disclaimers section in README.md](./README.md#disclaimers--read-before-using).
For contribution guidance, see [CONTRIBUTING.md](./CONTRIBUTING.md).

If you encounter a problem, the responsibility for remediation rests
with you, the user. Security responsibility rests with you, the user,
not with this repository. There is no private disclosure path, no
security advisory channel, and no commitment to triage reports. Read
the code, run the tests, and decide whether the toolkit fits your
threat model.
