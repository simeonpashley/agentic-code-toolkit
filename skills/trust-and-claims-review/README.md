# Trust and Claims Review Skill

Reviews whether public, user-facing, sales, product, privacy, security, AI, performance, and trust claims match evidence and implementation reality.

This skill is project-agnostic and designed to sit beside focused review lenses such as:

```text
doc-reviewer
code-reviewer
security-review
architecture-review
maintainability-review
privacy-review
```

The skill is not legal, financial, medical, security, or compliance advice unless explicitly scoped as a review lens. It identifies issues, missing evidence, tradeoffs, escalation points, and decision risks.
