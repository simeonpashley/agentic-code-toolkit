# Claim Types

## Privacy Claims

Examples:

```text
private
anonymous
no tracking
no ads
no AI training
local-only
zero-knowledge
end-to-end encrypted
```

Evidence needed:

- data flow
- logging policy
- analytics setup
- subprocessors
- current implementation
- privacy policy
- admin access model

## Security Claims

Examples:

```text
secure
encrypted
secure deletion
enterprise-grade
SOC 2
ISO 27001
```

Evidence needed:

- architecture
- controls
- certificates if claimed
- incident process
- backup/deletion semantics
- penetration testing if claimed

## AI Claims

Examples:

```text
AI-powered
no AI
AI does not train on your data
human-reviewed
automated decision
```

Evidence needed:

- model/vendor list
- data sent to AI
- retention/training terms
- user disclosure
- fallback/human review
- current vs planned

## Performance Claims

Examples:

```text
fast
instant
real-time
always available
99.9%
```

Evidence needed:

- metrics
- monitoring
- SLA/SLO
- scope
- fallback behaviour

## Customer/Traction Claims

Examples:

```text
trusted by thousands
loved by teams
used by leading companies
```

Evidence needed:

- real users/customers
- permission for logos
- source data
- date range

## Health/Outcome Claims

Examples:

```text
improves anxiety
treats burnout
clinically proven
```

Evidence needed:

- clinical/legal review
- study evidence
- regulated-claims review
- careful disclaimers
