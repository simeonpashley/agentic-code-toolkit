# Claim Rewrite Patterns

## Overbroad to Scoped

Bad:

```text
Your data is completely private.
```

Better:

```text
Your private content is not used for ads or AI training.
```

## Future to Current

Bad:

```text
End-to-end encrypted writing.
```

Better:

```text
End-to-end encryption is planned. The current release uses standard cloud storage with documented controls.
```

## Vague to Measurable

Bad:

```text
Fast sync.
```

Better:

```text
Designed to sync recent changes within a few seconds on a normal connection.
```

## Superiority to Fit

Bad:

```text
The best tool for everyone.
```

Better:

```text
Built for people who want a focused daily writing ritual rather than a full notes archive.
```
