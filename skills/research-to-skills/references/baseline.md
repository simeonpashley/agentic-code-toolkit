# Baseline

Without this skill, the observed failure modes were:

- research, proposal drafts, source digests, and active skill guidance mixed in one skill folder;
- active skill edits made before a durable research corpus existed;
- active skill wording included source names, confidence language, and research-summary phrasing;
- weak or medium findings risked becoming mandatory checks;
- cleanup used a too-broad restore/delete approach instead of verified micro-steps.

The new skill must make those failures difficult to repeat.
